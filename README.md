# Caprichos de la Abuela 🍕

Plataforma web a medida para la digitalización de menús, optimización de pedidos y gestión de presencia online en el sector culinario. 

La comida casera más rica que puedes comer fuera de casa, ahora potenciada con una experiencia digital fluida.

## 🚀 Características Clave
* **E-commerce Gastronómico:** Interfaz corporativa limpia y atractiva diseñada específicamente para la conversión y simplicidad en la toma de pedidos.
* **Rendimiento Optimizado:** Implementación de optimización avanzada de imágenes para garantizar una carga ultra rápida en cualquier dispositivo móvil.
* **Despliegue Profesional:** Infraestructura moderna configurada para un escalado estable y eficiente.

## 🛠️ Stack Técnico
* **Frontend & Framework:** Next.js, React, TypeScript.
* **Estilos:** Tailwind CSS.
* **Plataforma de Despliegue:** Vercel.
